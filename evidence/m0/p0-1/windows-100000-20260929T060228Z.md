## Interpretation boundary

At this 100k Windows point, the segment candidate again showed lower append time, enumeration time and rebuild time than the one-file-per-event candidate. Both repository crash probes behaved as designed for their synthetic interruption model.

No architecture decision is made from this run. P0-1 still requires:

- Windows run metadata capture for this run
- matching macOS 100k evidence
- 500k evidence on macOS and Windows
- initial and incremental Syncthing measurements
- Windows physical allocation evidence
- purge-complexity analysis
- corruption-blast-radius analysis
- ADR-0013 review and acceptance
