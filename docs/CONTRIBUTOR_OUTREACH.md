# Cryptex contributor outreach kit

Maintainer-ready messages for inviting **voluntary open-source contributors**. These are templates, not evidence that announcements have been posted. Share only in communities whose rules permit project showcases or contributor requests. Answer questions and link to a real, small issue rather than mass-posting the same message.

## Short post — GitHub Discussions / developer communities

**Title:** Looking for open-source contributors: Cryptex (Rust, Tauri, MCP, Obsidian)

Hi! I'm building [Cryptex](https://github.com/gungortarik/cryptex), a local-first, event-sourced personal memory engine for AI tools.

The goal is to make personal AI memory durable, searchable, inspectable and user-controlled, without depending on a hosted memory database. It's written in Rust with a Tauri/React desktop interface, SQLite FTS5, an Obsidian-compatible projection and an early MCP integration.

This is **pre-release software**, not a finished or audited product. I'm looking for contributors who enjoy Rust, TypeScript/React, desktop UX, local-first tooling, documentation, or thoughtful testing on Windows and macOS.

You can start with a small, clearly scoped task — no repository write access or cryptography experience is needed for many tasks:

- [Beginner-friendly tasks](https://github.com/gungortarik/cryptex/issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22)
- [Contribution guide](https://github.com/gungortarik/cryptex/blob/m0/foundation/FIRST_CONTRIBUTION.md) *(available after the onboarding PR is merged)*
- [Repository](https://github.com/gungortarik/cryptex)

Feedback, bug reports and reviews are welcome too. If a task looks interesting, please comment on its issue first.

## Before posting

- Confirm the README and linked contribution guide are merged and publicly readable.
- Verify a fresh clone can run the advertised demo and that any screenshots use only synthetic data.
- Clearly mark beta/incomplete integrations. Avoid claiming independent audits or production-grade security certification.
- Pick 1–2 relevant communities, adapt the text to their rules and ask a genuine question.
- Revisit and respond to feedback; don't post repeatedly without product progress.
